# JourneySpine

The order a journey's stages move through the six lanes — the visual signature of Greenfield, Brownfield, Feature Change and Bug Fix.

- **Provide:** `journey`, `stage`, `width`, optional `centers` (measured lane centres), `height`, `showLanes`, `onStage`.
- Forward hops arc above, backward hops below; done solid, future dashed; current dot in `active`. Dot numbers hide when space is too tight.
- Use above the graph and in Overview; never as decoration.
