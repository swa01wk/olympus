# ProvenanceBadge

Knowledge-class marker: FACT, INFERENCE, UNCERTAINTY, ASSUMPTION or DECISION, optionally with confidence.

- **Provide:** `kind`, optional `conf` (0–1), optional `source` (shown in the tooltip).
- Put it beside every claim recovered or inferred by an agent. INFERENCE and UNCERTAINTY are dashed; DECISION uses `active`.
- An ASSUMPTION must never appear on a canonical record.
