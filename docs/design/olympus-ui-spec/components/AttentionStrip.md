# AttentionStrip

The single highest-priority reason the operator is needed, with "Why this state?" and "Inspect <record>".

- **Provide:** `journey`, `stage`, `onSelect`, `onWhy`, `onAction`.
- Priority: checkpointed → decision → missing evidence → review → pending approval → inference → failed → blocked. Additional items are linked inline.
- When nothing needs the operator, say so ("Nothing needs you") and name what happens next. Never show a progress bar here.
